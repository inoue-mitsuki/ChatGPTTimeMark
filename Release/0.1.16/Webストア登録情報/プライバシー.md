## 単一用途

必須・文章入力。作成済み。コードとSPECに基づく。

```text
ChatGPTのユーザーメッセージの作成日時を、現在表示している投稿に対応させて、端末の現地時間で秒まで表示します。
```

## 権限の理由・リモートコード

| 項目 | 必須区分・操作 | 登録内容・状態 | 確認元・不明点 |
|---|---|---|---|
| API permissions・追加host_permissions | 確認専用 | 未宣言、確認済み | manifest |
| content_scripts対象サイト | 条件付き・理由入力 | 以下の完成文、作成済み | 入力欄は実画面で確認 |
| リモートコード | 必須・選択 | 使用しない、コード確認済み | 同梱JSのみ、eval・外部importなし |

```text
https://chatgpt.com/*のページ内で、ChatGPTが提供するメッセージIDと作成日時を参照し、対応するユーザーメッセージに日時を追加するために使用します。ChatGPTをiframeで開く場合も各フレーム内で処理します。ほかのサイトへのアクセスは宣言していません。
```
